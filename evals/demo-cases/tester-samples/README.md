# Tester samples

These are fictional demo materials. People, companies, products and tests in these files are invented. No loader reads this folder yet.

Only the `01`–`03` bundle files (the html and pdf next to this README) are ever uploaded to the tool. Never upload `key/`. `key/` is the tester answer key. Do not show it to the tool or the participant.

- `01-hartley-garden-suite-brief` and `02-mehta-drawing-notes` are applicant inputs.
- `03-sco-submission-bundle` is the planted-gap package for the officer timing protocol in `docs/user-testing/` (Round 1b).
- [`key/03-sco-bundle-TESTER-KEY.md`](key/03-sco-bundle-TESTER-KEY.md) is the tester answer key.
