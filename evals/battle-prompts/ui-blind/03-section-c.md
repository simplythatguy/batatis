# UI-B03 — Section C attributions

Build the Section C screen for confirmed articles.

## Required capabilities (do not omit)

- Table of articles with columns for code/standard, article, objective, functional statement, intent, and a per-article explainer.
- Make it obvious that objective / function / intent come from **lookup** (not free-typed AI memory) — e.g. source/registry indicator.
- **Retrieved code text** must be visually distinct from **AI explanations**.
- Support multiple articles in one view.
- Flag empty attribution cells as administrative gaps.
- Actions: Re-run lookup, Continue to evidence / Section D planner, Back to ranking.
- Navigation to other workflow steps.
