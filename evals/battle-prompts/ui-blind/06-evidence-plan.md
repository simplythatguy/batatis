# UI-B06 — Section D evidence plan

Build the Section D documentation / evidence plan screen.

## Required capabilities (do not omit)

- List planned evidence items the **applicant must supply** (document name + responsible org / lab).
- Status per item: not uploaded / uploaded / planned — and every “required but missing” upload must appear in the **same administrative gap list** used on intake, SCO, and export.
- Make authorship clear: this tool does **not** author test results or engineering opinions; provenance notes stay secondary to status.
- Upload (or attach) action updates status and clears that item’s gap.
- Actions: Continue to export / Back to Section C; navigation consistent with the product shell.

## Out of scope

Do not invent ISO numbers, test conclusions, or professional opinions to “fill” Section D.
