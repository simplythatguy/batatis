Time (150 wpm): 0:53–1:11 | Spoken words: 46 | At 150 wpm: 18.4 s | At 140 wpm: 19.7 s

Slide detail

  • Built by script from the official NBC(AE) 2023; the codedb README on dev names the 2nd printing; the SHA-256 pin is in draft PR #12
  • In the identify step (command line on dev; HTTP in draft PR #12), a citation that doesn't quote the code word for word is removed; app search shows database rows, and some article-level rows have no text yet
  • Identification (draft PR #12; pinned 2025-04-14 models): C$0.027 per case, 4.5 s median, 9.1 s p95 (measured, 20 dev cases, mean of 3 repeats, identification step only (excludes the completeness judge and Section D))

Background

Hallucinated citations are the failure that would sink an application, so the identify step's verifier (command line on dev) drops any citation whose quote doesn't match the code text. Each Section C row carries its article, objective and function from the attribution tables (where the attribution table has a row; otherwise the screen shows that the lookup is not available), so the rationale follows the code's own structure; the three demo articles were checked against our code database. Code identification (draft PR #12, not on dev): top-1 0.758 and recall@5 (correct article in the top 5) 0.758 (MRR 0.761) on the 11 model-checked dev cases that have a gold article (mean of 3 repeats, in-sample, not human-verified; the 4 ask cases are scored separately, top-1 0.25 at most; 5 cases have no gold); the BM25 baseline gets top-1 0.455, and a 700-character verifier variant reaches recall@5 0.818; it asks the applicant on 42% of cases. These are dev cases, not real applications, and the models are pinned to dated 2025-04-14 snapshots in draft PR #12.
