# Verification and claim limits

The 95% accuracy objective is not established. This branch repairs source packets, exposes previously hidden document-review findings, and provides a network-free Codex Luna diagnostic runner. It does not replace the hosted inference transport, certify engineering correctness, or approve any design.

## Implemented behavior

- The Questions flow exposes advisory review facts with status, exact source/page excerpts, conflicts, edition-specific provisions, evidence requests and next questions. It does not confirm facts or change blocking completeness gaps.
- Reopened input is matched against the stored intake SHA-256. A changed or unverifiable description cannot be presented as a current model review. File edits, including removing the last attachment, invalidate the previous review until reread. Unknown/off review states cannot display model-generated flags; failure states retain deterministic unread flags.
- The five v2 local packets explicitly supply the historical/reference records named in their prompts. SPV-001 R4 remains version context; the drawing-only L14-003 packet retains its excluded profile. The 653 existing split assignments and 592 source groups remain unchanged.
- Codex staging binds candidate and judge responses to exact requests, model/options and task identities. Results bind to the frozen inputs and call receipts. Generic judge caches cannot bypass that boundary. Missing, invalid, failed and unread work cannot satisfy the local coverage gate; a custom selection cannot stand in for both cities.
