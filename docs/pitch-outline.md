# Batatis: Pitch Deck Outline and 3-Minute Demo Narration

*Building Codes Challenge, Submission 1 (Oct 29, 2026). Sources were read Oct 20, 2026. Every number cites its source. Anything not on the `dev` branch today is marked **[if merged: PR #N]**. The end-to-end applicant flow is in review in PR #16, not yet on `dev` (it reaches the engine-filled form PDF; identification is still command line only): the demo films those screens. The engine fills the SCC form; in the app (PR #16, in review), Check completeness opens a review and the official PDF stays locked until there are 0 blocking gaps; then Download application PDF gives the Council's October 2026 variance form, filled in by the engine, unsigned, officer Part 2 blank, with a notice that it is not a finding that the design complies; the review also offers Download draft PDF and Download text record. A **cached demo run** is a recorded real model run for a seeded example case, replayed and labelled as such on screen instead of a live model call. Evaluation figures are model-checked, not human-verified, and are labelled that way.*
