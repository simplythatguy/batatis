# Use what the applicant gave; ask only what is missing or unclear

Intake used to store every value it read as unconfirmed and ask the applicant to confirm each one. A description with two PDFs produced more than 100 "Did we read this right?" cards, including the same city read on 21 pages, so the applicant redid work they had already done. From 2026-10-26 (user decision) intake confirms a value whose words it found and checked in the applicant's own description or files, stores a value read many times once, and asks only where the sources disagree, where the model guessed without a quote, or where a reading contradicts an answer the applicant gave. A value still needs a source in the applicant's own material, so Batatis never fills a blank, and every value stays editable on the review page. Turned down: one summary card listing every value read, because it still asks the applicant to re-check their own words.

An attachment is not automatically a statement about the current project. Intake identifies project passages before running field extraction: an explicit project brief or first-person construction proposal establishes project context; reference headings, examples and quoted requirements end it. Unclassified passages stay outside project fields and conflict questions. Populated mapped form fields are read separately from printed instructions; leading reference material also excludes filled example fields. Citations and full document review remain available regardless of project context. Issuer addresses and report dates do not supply applicant fields without explicit project labels.

This conservative structural reader does not classify every possible report. If it cannot identify project passages, the file receipt explains how to supply project facts. Quote verification and project context are separate checks. Re-running intake replaces prior machine readings from re-read files, including earlier automatic confirmations, while keeping explicit applicant answers and confirmations. Existing cases need that re-run to correct earlier readings; opening a saved case alone does not rewrite it.
