# Use what the applicant gave; ask only what is missing or unclear

Intake used to store every value it read as unconfirmed and ask the applicant to confirm each one. A description with two PDFs produced more than 100 "Did we read this right?" cards, including the same city read on 21 pages, so the applicant redid work they had already done. From 2026-10-26 (user decision) intake confirms a value whose words it found and checked in the applicant's own description or files, stores a value read many times once, and asks only where the sources disagree, where the model guessed without a quote, or where a reading contradicts an answer the applicant gave. A value still needs a source in the applicant's own material, so Batatis never fills a blank, and every value stays editable on the review page. Turned down: one summary card listing every value read, because it still asks the applicant to re-check their own words.
