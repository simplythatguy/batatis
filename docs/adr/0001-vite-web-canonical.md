# `web/` is the canonical frontend

`web/` (Vite) is the canonical frontend because it already has the Describe, Code check, Section C, and Application screens wired to the engine. Linear shadcn tokens from `feat/linear-shadcn-kit`'s `apps/web` were ported into `web/` through `docs/design/tokens.css`. `apps/web` is frozen: not merged as the product frontend, and not developed.
